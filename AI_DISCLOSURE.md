# AI assistance disclosure (NASA Space Apps "Use of Super Intelligence")

- **Code, data processing and documentation:** the React application, the Python ETL script (`etl/build_readings.py`), the flagging/recovery logic, the README and the pitch materials were developed with the assistance of an AI model (Claude, by Anthropic), directed, reviewed and tested by the developer.
- **Audio:** the narration voice in the project demo video is AI-generated (Kokoro text-to-speech, run locally via sherpa-onnx). It is not a human recording.
- **Images and video:** no AI-generated imagery is used. The demo video is assembled from screenshots of the application and slides, with captions.
- **Data:** all biomarker values come directly from NASA OSDR files (OSD-569, OSD-575). No values were generated or estimated by AI. A data-quality artifact in NASA's file is documented in the app (Data & Methods).
- No NASA logos, flags, or mission identifiers are used or modified.
